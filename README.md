One line, under 200 characters, about crypto and trading life. A judge model reads them two at a time and picks the funniest.

The entry is a single original joke about buying the dip — a setup with a turn, true to trading life, and a punchline at the end:

> I bought the dip. The dip bought a shovel, dug deeper, and now my portfolio pays rent in the basement.

## Run it

```sh
python3 main.py
```

The program writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and reads it back to verify the bytes.
